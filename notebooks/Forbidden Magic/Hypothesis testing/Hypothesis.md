In criminal cases, the defendant is **innocent (NULL)** until proven **guilty (ALTERNATIVE)**

| Instead of...          | Think...                           |
| ---------------------- | ---------------------------------- |
| Null hypothesis        | **Default assumption**             |
| Alternative hypothesis | **What you're trying to prove**    |
| Reject null            | **Found evidence for change**      |
| Fail to reject null    | **Not enough evidence for change** |
Null is
- Baseline
- Default
