# AI vs ML vs DL 
**AI** is the larger umbrella term; a simulation of human cognition
**ML** is a subset uses algorithms and requires feature engineering
**DL** uses multi-layered NNs and automatically extracts features from big data

# Learning
**Supervised** - Labeled data
**Unsupervised** - Works without labels by finding patterns in data
**Semi-supervised** - Trains on a relatively small subset of data that is already labeled and iteratively retrains itself by adding new labels that it generates with reasonably high confidence
**Reinforcement** - Interacts with environment and learns from feedback from environment
