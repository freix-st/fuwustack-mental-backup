# Things to look out for
Errors
Different formatting
Missing data

- Clean data to remove irrelevant data
- Remove extreme values
- Missing values should be removed or replaced
- Each data column should be in the proper format
- Create new features
    - Ex. a dedicated column for the average transaction duration for a user with a certain product to determine the products the user is interested in

- EDA
- Identify how to split the data into training and testing sets
