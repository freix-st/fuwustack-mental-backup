Can be used for both classification and regression
- Classifies by identifying hyperplane

Balance between maximizing margin controlled by parameter C
- Smaller C allows more misclassifications (softer margin)
- Larger C forces a stricter separation (harder margin)

Margin - the distance from the hyperplane to the nearest data point of a class
Kerneling - if the data is non-linearly separable, map the data to a higher dimension where a flat plane can separate it
